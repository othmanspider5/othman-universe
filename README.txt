# OTHMAN UNIVERSE

A responsive creator/fan website starter for Othman Lammallah.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser (Chrome or Edge recommended).

## Admin dashboard
- Click **Admin** in the header.
- Access code: **1889**
- Manage projects, news, fan messages, sections, site text, accent color, custom CSS/JS, and backups.

## Included sections
Home, Projects, News, Fan Zone, Fan Wall, About Me, and a private dashboard.

## Important notes before publishing
- This is a static starter version. Content and settings are stored in the browser's localStorage, so they are local to that browser/device.
- Fan messages submitted by visitors are not shared with other visitors yet. To make a real public community wall, connect a backend/database and add moderation.
- The 1889 code is a front-end demo lock, not secure authentication. Anyone who inspects the website files can discover it. Before making the dashboard public, replace this with server-side authentication and access control.
- Custom JavaScript runs in the page context. Only use code you trust.
- Replace or update the sample project links and text from the dashboard.
